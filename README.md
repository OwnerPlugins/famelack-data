# Personal Fork — OwnerPlugins/famelack-data

This is a **personal fork** of [famelack/famelack-data](https://github.com/famelack/famelack-data).

The dataset is kept up to date automatically with the upstream repository. All original data and structure come from upstream — no ownership is claimed over the dataset itself.

## How this fork handles customizations

To avoid conflicts during automatic syncs, **personal changes are never applied directly to `it.json`** (or to any other upstream file). Instead, they are stored in a dedicated override file:
tv/raw/countries/it.local.json

### How it works

On every sync run:

1. `tv/raw/countries/it.json` is fetched fresh from upstream.
2. The override file `tv/raw/countries/it.local.json` is read.
3. A merge is performed:
   - Channels present **only in upstream** → kept as-is.
   - Channels present **only in `it.local.json`** → added to the output (new channels).
   - Channels present in **both** → the version from `it.local.json` wins (modified channels).
4. The merged result is written back to `tv/raw/countries/it.json`.

### Adding a new channel

Add an entry to `tv/raw/countries/it.local.json`:

```json
[
  {
    "nanoid": "unique_id_here",
    "name": "Channel Name",
    "sources": {
      "streams": ["https://example.com/stream.m3u8"]
    },
    "languages": ["ita"],
    "country": "it",
    "isGeoBlocked": false
  }
]
```
Modifying an existing channel
Add an entry to it.local.json with the same nanoid as the upstream channel you want to override. At the next sync, your version will replace the upstream one in it.json.

Notes
Do not edit it.json directly — it is overwritten on every sync.

The nanoid must be unique unless you intentionally want to override an existing channel.

The file must contain valid JSON (watch commas and brackets).


 
 
 # 📡 Famelack Data

Official public dataset powering **Famelack**, with curated live TV, online radio, and live webcam streams from around the world.

## What this dataset includes

- Live TV, online radio, and live webcam streams from around the world
- IPTV, YouTube Live, browser-compatible video, and direct audio sources
- Language, country, and category metadata
- Organized JSON files under `tv/`, `radio/`, and `webcams/`

## Folder structure

```text
tv/
├── compressed/
│   ├── countries/
│   ├── categories/
│   └── countries_metadata.json
└── raw/
    ├── countries/
    ├── categories/
    └── countries_metadata.json

radio/
├── compressed/
│   ├── countries/
│   ├── categories/
│   └── countries_metadata.json
└── raw/
    ├── countries/
    ├── categories/
    └── countries_metadata.json

webcams/
├── compressed/
│   ├── countries/
│   ├── categories/
│   └── countries_metadata.json
└── raw/
    ├── countries/
    ├── categories/
    └── countries_metadata.json
```

Metadata files exist in both compressed (gzip) and raw (plain JSON) forms.

## How the data is maintained

This dataset is generated by the Famelack ingestion and validation pipeline:

- Stream uptime and reliability checks run regularly
- Broken or non-working streams are removed automatically
- YouTube live sources are verified for embed and live status
- Radio streams are validated for browser playback compatibility
- Webcam streams are validated for browser playback and live availability
- Newly discovered and verified sources are added continuously
- DMCA and rights-holder requests are respected

If a stream doesn't work reliably, it doesn't stay.

## Upstream acknowledgment

Famelack benefits from the open-source community. A significant portion of the TV discovery workflow is sourced from the [iptv-org](https://github.com/iptv-org/iptv) community, which we refine through:

- Automated validation and uptime monitoring
- CORS and playback compatibility checks
- Removal of broken or duplicate streams
- Corrected metadata and standardized country assignment
- Integration of additional verified sources not found upstream

The radio dataset is curated and maintained independently by Famelack, built from multiple publicly accessible sources and validated in-house.

The webcam dataset is also curated and maintained independently by Famelack from publicly accessible live webcam sources and validated in-house.

This repository is not a mirror. It is continuously transformed, filtered, and enriched to support the Famelack platform.
